# 发布与更新

## 统一版本

根包、Obsidian 插件、浏览器扩展、Codex 插件和运行时使用同一语义版本。标签格式为 `v<版本>`。

## Release 资产

标签触发 GitHub Actions：

1. 安装锁定依赖。
2. 运行类型检查、全部测试、生产构建和隐私门禁。
3. 从白名单目录组装四个平台资产。
4. 生成 `update-manifest.json` 和 `SHA256SUMS`。
5. 发布稳定 Release。

四个平台共享一套 JavaScript 实现，平台资产只区分安装入口与支持标识。

## 更新事务

更新器下载适配当前平台的资产，核对 SHA256 后解压到临时目录。安装器先备份当前插件和同版本程序目录，替换失败时恢复备份。安装状态最后写入，个人 Vault 内容与 `device.json` 不参与替换。

Obsidian 只提示可用更新。实际更新必须由用户在 `zhixing-manager` 或命令行中确认。
