# 架构决策

## 目标

知行台套件向 Windows、macOS 和 Ubuntu 用户提供同一套自动采集、成果回顾、长期知识沉淀、诊断和更新能力。用户数据始终留在个人 Vault，公开仓库与 Release 只发布程序和虚构样例。

## 决策

1. **Obsidian 桌面插件作为工作台与前台补跑宿主**：展示每日成果、长期 Wiki、沉淀状态、组件健康和更新提示；启动本地 ChatGPT 接收器。插件打开时也会检查采集和遗漏的整理周期。
2. **一套 Node 运行时承担跨平台逻辑**：Codex CLI 使用 Hook 采集；Codex Desktop 使用带生产者版本的结构化会话事件增量采集。桌面来源按文件字节游标读取 `session_meta`、`event_msg` 和 `turn_context`，只接收桌面主任务的用户消息与完成事件，并用稳定事件 ID 去重。当前验证并允许 0.144 与 0.147 系列，其他版本停止推进对应文件游标。知识事务、主题队列、语义微批、安装、诊断和更新共享 JavaScript 实现。
3. **设备配置与程序分离**：Vault 路径、随机接收密钥、端口、安装状态和浏览器扩展写入操作系统配置目录。浏览器始终加载固定扩展目录，Release 清单只列程序文件，更新不会接触 Vault 数据。
4. **更新采用签名外的强完整性门禁**：GitHub Release 提供版本清单和 SHA256。更新先下载到暂存目录，校验全部文件，备份当前程序，替换失败立即回滚。用户必须明确确认执行更新。
5. **浏览器扩展使用离线队列**：Chrome、Edge 和 Chromium 共用 MV3 扩展。接收器离线时事件保留在浏览器本地，Obsidian 恢复后自动重试。Safari 暂不包含在首版支持范围。
6. **Codex 插件提供可读技能**：知识检索、工作历史调查和套件管理使用配置发现 Vault，不写死用户名或盘符。安装器为套件 Skill 写入所有权与内容哈希；同名旧内容先备份，用户修改产生冲突并保留。0.6.0 的无标记 Skill 只在与旧程序权威副本哈希一致时认领。Hook 安装器只对 `hooks.json` 做结构化增量合并。桌面采集对不受支持的生产者版本停止推进游标并报告兼容错误。
7. **语义 Agent 只读，事务程序写入**：每批 Agent 只读取冻结合同并返回 JSON 回执。确定性事务程序验证回执、生成双层 Wiki 和交叉链接，全部写入成功后才推进处理状态。
8. **飞书作为默认关闭的只读连接器**：同一 Node 核心通过官方 `lark-cli` 使用用户身份读取所选模块。Obsidian 提供五步设置、授权和状态入口；多维表格按名称查找或链接解析后，由用户直接选择数据表与视图。凭据保留在官方 CLI 的安全位置，Vault 只保存连接范围、增量状态和必要证据。

## 飞书数据链

`lark-cli 只读 API → raw/feishu/events/YYYY-MM-DD.jsonl → raw/feishu/daily/YYYY-MM-DD.md → 主题队列 → wiki/我的经历 + AI 证据 → 知行台视图`

- 身份作用域由租户与用户标识做不可逆哈希，稳定事件由作用域、资源类型、对象 ID 和版本组成。
- 同一对象的更新进入同一长期主题。跨飞书、Codex、Git 和 ChatGPT 的归并需要项目和 Issue/任务标识等明确证据。
- 每个模块独立保存游标、最后成功时间、失败次数、退避时间和访问状态。权限过期、撤权或删除会保留状态，不自动删除已经形成的个人经验。
- 消息必须来自用户选择的项目群，并通过工作内容策略；私聊、闲聊、机器人通知和重复广播不进入队列。
- 每次知识周期先尝试飞书增量同步。整理调度保存最后尝试、最后成功、下次执行、状态和错误；首次存在队列、错过日期或到达 23:30 时补跑，失败后按退避时间重试。
- 安装器在 Windows 启动目录、macOS LaunchAgent 或 Linux XDG Autostart 中注册一个套件自有入口，三端都运行同一个后台调度模块。后台进程登录后立即启动并独立于 Obsidian；睡眠、离线或错过 23:30 后在下一次心跳补跑。Obsidian 保留前台补跑作为降级路径。
- 后台宿主使用配置目录单实例租约；Desktop 采集、整理决策和手动整理使用 Vault 自动化租约。租约由随机所有权令牌、进程启动身份、心跳和过期时间共同校验；系统睡眠不会制造双宿主，崩溃或 PID 复用后可以恢复。
- 后台启动项带所有权标记与内容哈希。卸载只移除未被修改的套件启动项，不创建或恢复旧版三个 Windows 计划任务。

## 运行边界

- Obsidian 桌面插件无需全局 Node 即可浏览已有数据和接收 ChatGPT 内容。
- Codex Hook、命令行安装和自动语义整理需要 Node.js 22 或更高版本；安装器会先检测并给出明确提示。
- 自动语义整理还需要本机可调用 Codex CLI。缺少时保留原始记录并在健康状态中提示，不丢数据。
- 飞书连接器需要最新版官方 `lark-cli`，各模块实际可见内容同时受用户自身权限和企业应用权限约束。
- Release 覆盖 Windows x64、macOS Apple Silicon、macOS Intel 和 Ubuntu x64；CI 分别在对应架构 runner 解包并执行真实安装入口。
