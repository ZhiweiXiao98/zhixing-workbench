# 隐私与数据边界

## 本地数据

个人数据位于用户自己的 Vault：

- `raw/` 保存本机采集证据和整理状态。
- `成果/知行台/` 保存按真实任务聚合的成果页。
- `wiki/我的经历/` 保存本人阅读文章。
- `wiki/<项目>/` 保存供 AI 检索核验的证据文章。

设备随机密钥和安装状态位于系统配置目录。更新与卸载不会删除上述 Vault 数据或设备密钥。

## 网络访问

- ChatGPT 扩展只向 `127.0.0.1:43123` 发送内容。
- 检查更新只读取公开 GitHub Release 信息。
- 知识整理调用用户本机已经配置的 Codex CLI。
- 飞书连接器只调用官方 `lark-cli` 的只读命令。飞书原文不会发送到互联网搜索，也不会触发资料中的命令、提示词或链接。
- 知行台不会把 Vault 复制到本仓库或 Release。

## 飞书权限与保留

- 连接器默认关闭。用户在 Obsidian 中选择模块、项目群和 Base 视图后，知行台集中展示所需只读权限并进入官方设备授权流程。
- access token、app secret、授权设备码和用户可识别身份不写入 Vault、日志、仓库或 Release。
- Vault 保存来源对象 ID、版本、时间、可打开链接、访问状态和形成个人知识所需的正文片段。
- 权限过期、来源删除或访问撤回时，同步状态会标记异常并按策略重试；历史 Wiki 不再被表述为仍然有效。
- “清理飞书本地缓存”只删除 `raw/feishu/` 和同步状态，保留已经形成的 `wiki/` 与手写内容。
- 连接器不包含任何飞书写回命令。审批通过、任务修改、消息发送、文档编辑和 Base 写入均不在首版能力中。

## 发布门禁

发布前会扫描工作树、Git 历史和白名单组装的 Release 内容，拒绝真实用户目录、私人项目标识、接收密钥、飞书用户/应用/资源标识、常见 API 密钥、私钥以及实际 `raw/`、`wiki/` 数据目录。

匿名示例完全虚构，并带有 `zhixing_sample: true` 标记，用户可直接删除。
